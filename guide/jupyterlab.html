JupyterLab на вашем компьютере

Весь код уроков запускается в настоящем JupyterLab на вашей машине. Сайт показывает его во встроенном окне — ничего не выполняется на чужих серверах.

1. Как это устроено

  • Маленькая программа-помощник olympiadai-lab запускает на вашем компьютере настоящий JupyterLab с Python, NumPy, pandas, scikit-learn и PyTorch.
  • Он слушает только адрес 127.0.0.1 (ваш компьютер) и требует секретный код — из сети до него не добраться.
  • Сайт связывается с ним напрямую из вашего браузера и открывает его во встроенной рамке на вкладке Практика → JupyterLab.
  • Тренажёр упражнений (вкладка «Упражнения») и тензор-пазлы по-прежнему работают прямо в браузере и не требуют установки.
Нужно: Windows, macOS или Linux; около 2 ГБ свободного места; интернет при первой установке. Python ставить заранее не нужно — установщик uv скачает подходящий сам.

2. Установка (один раз)

  1. Откройте сайт → вкладка Практика → JupyterLab.
  2. Нажмите «Настроить компьютер (один раз)», выберите свою систему (Windows / macOS / Linux) и нажмите «Копировать». Команда подставляет правильный адрес сайта — не вводите её вручную с другой страницы.
  3. Откройте терминал:
    • Windows: меню «Пуск» → введите PowerShell → Enter.
    • macOS: Spotlight (⌘+Пробел) → Terminal.
    • Linux: Ctrl+Alt+T.
  4. Вставьте команду и нажмите Enter. Первый запуск скачивает библиотеки (включая PyTorch) — это займёт несколько минут, ничего не закрывайте.

Команда делает четыре вещи подряд: ставит uv, ставит помощник, запускает JupyterLab (up) и включает автозапуск при входе в систему (autostart on).

Команду, которую вы копируете, показывает сам сайт. Запускайте только её и только на своём компьютере. На школьных и рабочих компьютерах с ограничениями установка может быть запрещена — спросите администратора.

3. Подключение к сайту

  1. В конце установки терминал печатает ссылку вида https://…/#lab=8888:ваш_код и сам пытается открыть её в браузере.
  2. Сайт спросит «Подключить JupyterLab на этом компьютере?» — нажмите «Подключить». Код хранится только в этом браузере, и сразу после подтверждения исчезает из адресной строки.
  3. Слева вверху появится зелёная точка и надпись «Компьютер подключён · порт 8888». Готово.

Если окно не открылось само, скопируйте ссылку из терминала и вставьте в браузер. Потеряли ссылку — выполните olympiadai-lab up снова: команда безопасно запускается повторно.

4. Работа с уроком

  1. Откройте любой урок и нажмите «Открыть в JupyterLab» (кнопка вверху урока и в конце, на карточке «Практика»).
  2. Сайт кладёт блокнот урока в папку Документы/OlympiadAI/<модуль>/ (например, OlympiadAI/ML2/) и открывает его.
  3. Запускайте ячейки Shift+Enter. Перед выполнением кода прочитайте текст ячеек над ним — блокнот повторяет урок.
  4. Ваши правки не перезаписываются: если блокнот уже есть на диске, сайт откроет вашу версию. Хотите чистую копию — переименуйте или удалите файл и откройте урок снова.
  5. Файлы лежат на вашем компьютере; их видно и в обычном проводнике.

Проверка PyTorch и видеокарты

import torch
print(torch.__version__, torch.cuda.is_available())

Помощник ставит версию PyTorch для процессора (на Apple Silicon — обычную сборку). Для учебных блокнотов этого достаточно. Если вам нужна видеокарта NVIDIA, установите в окружение сборку PyTorch с CUDA по инструкции на сайте PyTorch; без этого torch.cuda.is_available() вернёт False — это не ошибка.

5. Каждый день

Если вы выполнили команду целиком, автозапуск уже включён: после перезагрузки JupyterLab поднимется сам, а сайт подключится через несколько секунд (он проверяет связь каждые 3 секунды).

КомандаЧто делает
olympiadai-lab upзапускает JupyterLab (если уже запущен — ничего не ломает)
olympiadai-lab statusпорт, номер процесса, рабочая папка, отвечает ли сервер
olympiadai-lab downостанавливает JupyterLab; сайт покажет «Компьютер не отвечает»
olympiadai-lab doctorпроверяет Python, место на диске, свободные порты, брандмауэр
olympiadai-lab autostart on|offвключает / выключает запуск при входе в систему

Если команда olympiadai-lab не находится, вызывайте её по полному пути: ~/.local/bin/olympiadai-lab (macOS/Linux) или %USERPROFILE%\.local\bin\olympiadai-lab.exe (Windows).

Кнопка «Отключить компьютер» под окном JupyterLab забывает подключение в браузере (сам сервер продолжает работать — остановить его можно командой down).

6. Если что-то не работает

Что видитеЧто делать
«Компьютер не отвечает» / «Сервер не отвечает»Выполните olympiadai-lab status, затем olympiadai-lab up. На сайте нажмите «Проверить ещё раз».
«Код подключения устарел»Сервер перезапускался с новым кодом. Выполните olympiadai-lab up и откройте напечатанную ссылку с #lab=… ещё раз.
«Браузер не даёт встроить локальный JupyterLab»Браузер блокирует сторонние cookie (так бывает в Safari, режиме инкогнито и Brave со строгой защитой). Нажмите «Открыть в новой вкладке» — всё остальное работает так же. Либо разрешите cookie для сайта.
Порт 8888 занятПомощник сам выберет 8899. Сайт возьмёт порт из ссылки подключения — просто откройте новую ссылку.
Команда не запускается на WindowsЗапускайте в PowerShell, не в «Командной строке» (cmd). Если политика запрещает скрипты, команда уже содержит -ExecutionPolicy ByPass только для установщика.
Нет места на дискеНужно около 2 ГБ. olympiadai-lab doctor покажет, чего не хватает.
Ошибка при импорте библиотекиУбедитесь, что блокнот запущен в ядре Python 3 из этого JupyterLab (правый верхний угол блокнота), а не в чужом окружении.
Безопасность: что именно открыто?
  • Сервер слушает только 127.0.0.1, то есть недоступен из локальной сети и интернета.
  • Каждый запрос требует случайный код, который хранится в файле с ограниченными правами и в вашем браузере.
  • Разрешённый источник запросов (CORS) — только адрес этого сайта, а встраивать JupyterLab в рамку может только он.
  • Подключайте только тот сервер, который запустили сами командой olympiadai-lab up.

7. Как всё удалить

olympiadai-lab autostart off
olympiadai-lab down
uv tool uninstall olympiadai-lab

Затем удалите папку Документы/OlympiadAI (там окружение, логи и ваши блокноты — скопируйте нужные файлы заранее). Сам uv можно оставить: он не мешает другим программам.

JupyterLab on your computer (English)

All lesson code runs in a real JupyterLab on your own machine; the site only embeds it in a frame. The exercise trainer and tensor puzzles keep working in the browser with no setup.

  1. Install once. Site → Practice → JupyterLab → “Set up my computer (once)”. Pick your OS, copy the command, run it in PowerShell (Windows) or a terminal (macOS/Linux). The first run downloads Python packages including PyTorch (about 2 GB, several minutes). It installs uv, installs the helper, starts JupyterLab and enables autostart.
  2. Pair. The terminal prints a link ending in #lab=8888:<code> and tries to open it. Click “Connect”. The code stays in this browser only. A green dot means you are connected.
  3. Open a lesson. Press “Open in JupyterLab” in any lesson. The notebook is written to Documents/OlympiadAI/<module>/ and opened; your edits are never overwritten. Run cells with Shift+Enter.
  4. Daily use. With autostart on, nothing to do. Otherwise: olympiadai-lab up; also status, down, doctor, autostart on|off.
  5. GPU. The helper installs CPU builds of PyTorch, which is enough for the lessons. torch.cuda.is_available() returning False is normal. For an NVIDIA GPU, install a CUDA build of PyTorch into the managed environment.
  6. Troubleshooting. “Not answering” → olympiadai-lab status then up. “Pairing code expired” → run up and open the new #lab= link. “Browser won't embed” → third-party cookies are blocked; use “Open in a new tab”.
  7. Uninstall. olympiadai-lab autostart off, olympiadai-lab down, uv tool uninstall olympiadai-lab, then delete Documents/OlympiadAI.
