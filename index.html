Tensor puzzles

One line of broadcasting per puzzle, no loops. Train the run → read → fix loop — one 25-minute sprint a day.

Rules

  • One line: return …, under 80 columns.
  • Allowed: arange, where, @, arithmetic, comparison, .shape, any indexing (a[:, None], a[arange(3)]) and your earlier puzzle functions.
  • Not allowed: anything else — no np.*, .sum, loops, if, lists.

Puzzles by Sasha Rush (MIT). Runs real Python + NumPy in your browser.
